# Cravinos

Build a mobile-responsive web app for a restaurant Kitchen Display System (KDS) using Tailwind CSS, Lucide icons, and React. Create a clean top navigation bar with a brand title ("Cravinos"), an active shift timer (HH:MM:SS), a green status badge ("Live Sync" with a pulsing dot), and tab buttons to switch between three staff views: 1) Cashier Terminal, 2) Kitchen Display (KDS), and 3) Customer Ready Board. Use a modern dark theme interface.



## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
